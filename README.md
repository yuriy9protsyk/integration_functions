# Вишмат · Лекція № 10 — Інтерактивний конспект з інтегрування

Інтерактивний EdTech-конспект і тренажер з вищої математики за матеріалами **Лекції № 10 (§ 13)**:
1. Інтегрування частинами
2. Інтегрування дробово-раціональної функції
3. Інтегрування ірраціональних функцій
4. Тригонометричні підстановки
5. Інтегрування виразів із тригонометричними функціями

## Стек
- **Next.js 15 (App Router)** + **TypeScript** + **Tailwind CSS v4**
- **shadcn/ui** (`Slider`, `Tabs`, `Card`, `Badge`, `Tooltip`) + **lucide-react** + **framer-motion**
- **KaTeX** (`trust: true`, X-Ray формули з підсвіткою змінних)
- **Mafs** (інтерактивні 2D-графіки, суми Рімана, рухомі межі інтегрування)
- **mathjs** (обчислення функцій і чисельного інтегрування в реальному часі)
- **Zustand** (синхронізація підсвітки змінних між формулами та графіками)

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000) у браузері.

## Збірка

```bash
npm run typecheck
npm run build
npm run start
```
